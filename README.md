<p>O To Do List - Ignite foi um projeto feito no começo dos meus estudos do <strong>React</strong>. Nele há o uso do UseState para obter um array das listas e manipular ela. Foi bom para a memorização e entendimento dos hooks e componentes básicos.</p>

# Funcionalidades do projeto

- `Criar uma tarefa`: Você pode postar um comentário em um post já existente.
  ![Imagens sobre postar um comentário](https://github.com/user-attachments/assets/7a6cd1b9-46a6-4c32-a755-b903516f5daf)
  

- `Marcar Tarefa como completa`: Clicando no checkbox. Você pode marcar a tarefa como concluída.
  ![Imagem sobre aplaudir o comentário](https://github.com/user-attachments/assets/d01f30a3-caef-4f49-946d-9ad1e0b12eed)

- `Excluir Tarefa`: Caso queira excluir alguma tarefa, clique no ícone da lixeira.




# Técnicas e tecnologias usadas
- `React + Vite`
- `Css Modules`
- `UseState`
- `Componentes`
